# Velocity Garage Manager

A modern C++17 garage inventory management system designed with clean software engineering principles and modern STL practices.

---

## Features

- Modern Object-Oriented Design
- Persistent File Storage
- Duplicate Car Prevention
- Advanced Search System
- Garage Analytics Dashboard
- Sorting & Filtering
- Exception Handling
- Clean Console UI
- Modern STL Algorithms
- Structured Data Serialization

---

## Technologies Used

- C++17
- STL
- File Handling
- Object-Oriented Programming
- Modern C++ Practices
